Rekordis: user-started activity recording

Demonstration of the location foreground service for Google Play review.

Open the video directly

  1. The user starts an activity while the app is visible.
  2. Recording continues on the home screen. An ongoing notification shows recording status.
  3. The user returns, pauses, resumes, then finishes and saves the activity.

The service is needed to record a continuous workout route while the screen is locked or another app is open. Delaying recording loses the start of the route; interruption leaves gaps. Recording starts from an explicit foreground action and ends when the user finishes.

Recorded in an isolated Android emulator demonstration build using the app's native UI and foreground-service implementation. GPS coordinates, storage and Plus access are test fixtures. This is a behavioral demonstration, not evidence of a real payment, real-world GPS accuracy or battery endurance. No personal location data is included. Production package: com.wowcoded.rekordis, version 0.1.0 (2).
